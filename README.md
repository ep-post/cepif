## How to upload to GitHub (no folders — just drag all files)

1. Go to your GitHub repo → **Add file → Upload files**
2. Select ALL files from this folder and drag them in
3. Click **Commit changes**
4. Go to **Settings → Pages → Branch: main → / (root) → Save**
5. Live in ~60 seconds ✓
